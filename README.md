# Drink Sirf · Brand Manual

The Sirf brand manual, by Black Prism Designs. The published `index.html` is password protected:
the manual is encrypted and only opens in the browser with the right password.

To update it, edit `manual.html` (kept locally, never committed), then rebuild and push:

```
node build-gate.mjs
git add -A && git commit -m "Update manual" && git push
```
